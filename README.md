# WideMCP

Production MCP servers that actually work.

WideMCP is an open-source, local-first platform for curated MCP servers and orchestration around widely used open-source tools.

We focus on reliability, trust, documentation, and privacy.

## Principles

- Local-first
- Privacy-first
- Production-quality
- Open source
- Human-controlled actions

## Initial focus

- Audio/video processing
- Home automation
